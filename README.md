# Rues de Paris

A browser quiz: type the names of Paris streets and watch them light up,
colored by arrondissement, on a real map built from OpenStreetMap
geometry — 5,820 streets and bridges sourced from French Wikipedia's
street categories, set against the Seine, major parks, and the city's
administrative outline. A second mode, the Daily Challenge, turns the
same map into a connect-the-dots puzzle between two Paris landmarks.

## Play

Just open `index.html` in a browser — double-click it, or:

```
open index.html
```

No server, no build step, no internet connection needed once the data
file exists (fonts load from Google Fonts if you're online; they fall
back to system fonts otherwise).

## Sharing with someone else

For sending to someone else, use the single-file bundle instead of the
raw project folder:

```
python3 scripts/bundle_standalone.py
```

This writes `rues-de-paris-standalone.html` — everything (CSS, JS, the
street data) inlined into one file, re-generated fresh from the real
source files each time you run it. Share just that one file. It avoids
two real problems with sharing the plain multi-file folder: Windows
lets you open a file from inside a `.zip` preview without extracting
it, silently stranding it from `style.css`/`game.js`/`data/`; and
Android Chrome blocks a standalone local HTML file from loading
sibling files via `file://` at all, regardless of how it was opened. A
single self-contained file has no sibling files to lose, so neither
problem can happen.

Pick a difficulty from the dropdown — each tier is a superset of the one
below it, ranked by a computed "fame" score (Wikipedia interlanguage
links + backlinks), not by street type:

- **Monuments** (50 streets) — the most internationally recognizable
- **Connues** (200, default) — well-known streets
- **Averties** (600) — local-knowledge level
- **Carte complète** (5,820) — every street and bridge in the dataset

Below the map, a 20-cell grid tracks progress per arrondissement (each
number fills with that district's Métro-line color as you find its
streets). There's no timer — just the running "found" counter and a
give-up button that reveals whatever's left, grouped by arrondissement.

Matching is lenient: accents, capitalization, hyphens, and the leading
"rue"/"avenue"/"place"/etc. are all optional — "republique",
"République" and "Place de la République" all match the same street.
When a bare name is genuinely shared by several streets (e.g. "arts"
matches "Pont des Arts", "Villa des Arts", "Avenue des Arts"...), typing
it once finds all of them at once; typing a full name always targets
that one street specifically. A street that's already found never
re-triggers on a later guess, so it can't interrupt you mid-keystroke
while typing a longer name that happens to pass through the same
letters (e.g. "Rue Le Brun" won't hijack an attempt to type "Boulevard
Brune").

## Daily Challenge

The "Défi du jour" button (next to Give up, in the header) switches to a
second mode: connect two well-known Paris places — one per arrondissement,
20 in the pool — by naming a real, physically continuous chain of streets
between them. The pair is picked deterministically from the date, so
everyone on the same calendar day gets the same puzzle.

- The two endpoints are given, not guessed — they're shown in the route
  header above the input, and don't need to be typed themselves.
- Any real connecting chain wins, not just the shortest one; a give-up
  reveals one valid route, dashed on the map.
- The timer starts on your first keystroke, not when you open the mode.
- "Afficher toutes les rues" shows every street in gray (with hover
  tooltips) instead of an empty map, for players who want to see what's
  actually nearby.
- Your best time for today is kept in the browser's local storage (per
  device, not synced) — reopening a solved puzzle shows it instead of
  resetting, with a "replay for fun" option that doesn't overwrite a
  faster time.

Five of the 20 places (Tour Eiffel, Gare de Lyon, the BnF, Parc des
Buttes-Chaumont, and Cimetière du Père-Lachaise) and one park square
(Square des Batignolles) aren't streets at all — they're geocoded
separately via Wikidata and spliced into the same street-adjacency graph
as ordinary points, each connected to its 3 nearest real, well-connected
streets (not just the single nearest point, which can land on an isolated
path with no other connections, e.g. inside a park).

## Re-running the data pipeline

The game reads `data/paris_streets.js`, a static file generated by
`scripts/fetch_streets.py`. To rebuild it (e.g. to refresh against newer
OSM/Wikipedia data):

```
cd scripts
pip install -r requirements.txt
python3 fetch_streets.py
```

This is a one-time/occasional build step — it walks Wikipedia's street
category trees (one master category, a type-level subcategory per
arrondissement, occasionally one eponymous category deeper for very
famous streets), makes one large OpenStreetMap Overpass query for all
of Paris's streets plus separate ones for its administrative boundary,
the Seine, and its parks, and scores every matched street's fame via a
few thousand individual Wikipedia calls (threaded — a few minutes on a
cold cache, seconds once cached). Responses are cached under
`scripts/cache/`, so reruns after the first are fast unless you delete
the cache. Inspect `scripts/build_report.txt` afterward for
match/collision/tier details — it's regenerated on every run.

## Data & attribution

- Street names and arrondissement grouping: French Wikipedia's street
  category tree, rooted at `Catégorie:Voie de Paris par arrondissement`
  (CC BY-SA). Bridges come from a separate category,
  `Catégorie:Pont sur la Seine à Paris`, since a bridge doesn't belong
  to any one arrondissement.
- Street, river, park, and boundary geometry: © OpenStreetMap
  contributors, ODbL.
- The 6 Daily Challenge landmark points not already covered by a street
  entry are geocoded via their Wikidata item, then located against the
  same OpenStreetMap data as everything else.
- Fame ranking: derived from Wikipedia interlanguage link and backlink
  counts — a heuristic, not an authoritative measure of renown.
- Arrondissement colors 1–14 are the official RATP Métro line colors;
  15–20 are chosen to stay visually distinct from those and from each
  other.

## Known limitations

(Current counts as of the last pipeline run — see
`scripts/build_report.txt` for the up-to-date figures after any rerun.)

- 262 candidate streets (out of 6,082, after the Wikipedia landmark and
  bridge supplements) aren't included — mostly small named squares or
  passages OpenStreetMap doesn't map as a separate `highway` way. See
  `build_report.txt`'s "Sample unmatched" line.
- 8 of 27 Wikipedia-listed bridges aren't included: Pont Amont, Pont
  Aval, Pont Barbier, Pont de Grammont, Pont Rouelle, and Pont
  Saint-Charles don't appear under a matching name in OSM's road data
  (likely lacking a distinct `name` tag); the Viaduc d'Austerlitz and
  Viaduc d'Auteuil are railway viaducts, tagged as railway rather than
  road infrastructure in OSM, so they fall outside this pipeline's
  street-and-bridge query entirely.
- A street spanning multiple arrondissements is colored entirely by the
  arrondissement its Wikipedia article was filed under (or, for
  landmarks/bridges resolved by location instead, by whichever
  arrondissement contains its midpoint), even where it physically
  crosses into another.
- Matching requires the input to reduce to a street's exact "core" name
  (accent/case/hyphen/prefix-insensitive) — partial names ("champs" for
  "Champs-Élysées") don't match.
